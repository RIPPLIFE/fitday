# FitDay 智能减脂盘

一个手机优先的 PWA。体重、饮食和训练数据默认只保存在浏览器本机；图片识别为可选功能。

## 手机独立版

`docs/` 目录是可以直接发布到 GitHub Pages、Cloudflare Pages 等静态托管的手机版。

- 热量、三大营养素、体重趋势和运动估算都在手机浏览器本地完成。
- 手动记录和离线基础功能不依赖电脑。
- 配置兼容 OpenAI Chat Completions 的视觉模型后，照片会由手机直接发送给所选服务商。
- API Key 保存在手机浏览器，不写入仓库，也不会进入 JSON 备份。
- 当前仓库不包含任何 AI 服务商 Key，也不默认绑定硅基流动。

修改 `public/` 后运行 `sync-phone.ps1`，即可把最新版同步到 `docs/`。

## 已实现

- 按基础代谢、日常活动、7 日体重趋势估算每日维持热量。
- 按减重速度和当天训练消耗实时调整当日热量目标。
- 实时显示剩余热量、蛋白质、碳水和脂肪。
- 每天第一次打开时主动询问今日体重，填写后立即更新趋势和目标。
- 支持按 RPE 强度记录共享单车、力量训练、跑步等多种运动。
- 支持体重、饮食、运动的增删与 14 天汇总。
- 支持手机拍照或选择图片，通过视觉模型估算食物热量和三大营养素。
- 支持读取包装“营养成分表”，按每 100 克、每 100 毫升或每份和实际食用量换算。
- 识别结果可手动修正后入库，不会直接写入。
- 支持 JSON 导入、导出和 PWA 安装。


电脑浏览器打开：

```text
http://localhost:4173
```

手机和电脑连接同一个 Wi-Fi 后，在电脑执行 `ipconfig` 找到局域网 IPv4 地址，例如：

```text

```

Windows 防火墙第一次弹出提示时，需要允许 Node.js 通过专用网络。

## 图片识别

推荐在启动服务前设置服务端密钥：

```powershell
$env:OPENAI_API_KEY = "sk-..."
$env:OPENAI_MODEL = "gpt-4.1-mini"
.\start.ps1
```

也可以在应用的“设置 > AI 接口”里填写 API Base URL、API Key 和视觉模型名称。密钥只保存在当前浏览器本地存储中，并随照片分析请求发到本机 Node 服务，不会写入数据导出文件。公开部署时优先使用服务端环境变量。

自定义 Base URL 需要兼容 OpenAI 的 `/chat/completions` 接口，并支持图片输入。更换服务商时通常只需修改 Base URL、Key 和模型名称。

如果使用兼容网关，可额外设置：

```powershell
$env:OPENAI_BASE_URL = "https://your-gateway.example/v1"
```

## 计算口径

- 基础代谢使用 Mifflin-St Jeor 公式。
- 没有足够数据时，使用基础代谢乘非运动活动系数估算维持热量。
- 当最近有至少 7 天完整饮食记录和体重趋势时，使用“平均摄入 - 体重变化对应的热量”估算维持热量。
- 蛋白质和脂肪先按每公斤体重分配，剩余热量分配给碳水；若目标过低，会在安全范围内下调脂肪和蛋白质。
- 训练消耗按 `MET × 3.5 × 体重(kg) ÷ 200 × 分钟 × 强度` 估算，可手动修正。

图片识别与任何热量估算都存在误差，只适合趋势管理，不能替代医学诊断或专业营养治疗。
